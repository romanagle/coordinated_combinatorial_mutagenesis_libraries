# Generated runs

This directory contains reproducible working state, not manuscript-facing results.

- `deepsquid/<target>/<wt>/`: deepSQUID working artifacts.
- `residualbind/<target>/<wt>/`: ResidualBind validation and training runs.
- `synthetic_negative_control/`: active motif-only negative-control run.

Final evidence belongs in `../outputs/ground_truth_collections/`. Runtime model weights belong in `../models/`.
