# ResidualBind VTS1 Figure Inputs

This directory contains the exact inputs used to regenerate the active
`../figures` files.

## Figure Provenance Label

Newly generated figures are stamped in the top-right corner with:

```text
Library: fresh|cached|unknown | made YYYY-MM-DD HH:MM
```

The timestamp is inferred from the newest input library/result file used for
that figure unless `FIGURE_LIBRARY_MADE` is set. The status is passed by the
plotting script when known, inferred from the input path when possible, or can
be forced with `FIGURE_LIBRARY_STATUS`.

## Training and Plotting Boundary

Training/evaluation artifacts are generated before plotting and reused by the
plot scripts. Plot scripts should only read libraries, JSON results, or saved
prediction artifacts; they should not train models.

For `scatter_by_mutcount.png`, run the training step once:

```bash
python mRNA_RBP/generate_residualbind_vts1_scatter_predictions.py --force
```

Then regenerate the figure from the saved artifact:

```bash
python mRNA_RBP/plots/plot_residualbind_vts1_scatter_by_mutcount.py
```

## Activity-Balanced Library

`activity_balanced.npz` is the activity-balanced evaluation library.

Initialization recipe:

- Exact-mutant candidate pools at 3, 5, 7, and 15 mutations.
- 50,000 candidates per mutation count, 200,000 total before global dedup.
- Candidates are scored by the ResidualBind VTS1 oracle.
- Scores are histogram-uniformized with 200 bins after clipping to the 1st and
  99th percentiles.
- Seed is `k * 10000 + 600`.
- Target size is 20,000, but the final deduplicated library may be smaller.

For the fresh active run, `activity_balanced.npz` contains 14,400 sequences.

## Files

- `activity_balanced.npz`: activity-balanced evaluation library.
- `ssm.npz`: fresh single-mutant library scores used to compute the SSM
  baseline in `model_comparison_bar_type3.png`.
- `pairwise_lib.npz`: targeted pairwise evaluation library.
- `type3.npz`: exhaustive SSM plus pairwise/triple evaluation library.
- `lib_size_spearman_results.json`: fresh surrogate evaluation results used by
  `rho_vs_libsize_type3.png` and `model_comparison_bar_type3.png`.
- `cross_mutrate_results.json`: fresh fixed-rate cross-mutation evaluation
  results regenerated from the fresh `mut05`, `mut10`, and `mut25` libraries in
  `cached outputs/fresh_pipeline_workspace_20260704`. This is the source for
  `vts1_cross_mutrate_heatmap.png` and the four
  `vts1_cross_mutrate_libsize_*.png` plots in `../figures`. It intentionally
  does not include a `mixed` column/row, because no fresh mixed library was
  promoted for this figure set.
- `scatter_by_mutcount_predictions.npz`: saved random-holdout and
  activity-balanced predictions for `scatter_by_mutcount.png`. This file is
  generated by `mRNA_RBP/generate_residualbind_vts1_scatter_predictions.py` and
  consumed by the plotting-only scatter script.
- `random_libraries/`: fresh high-WT random libraries from the pipeline run.
- `random_region_score_cache/`: high- and low-WT random-region score caches used
  for the two random-region distribution figures.
